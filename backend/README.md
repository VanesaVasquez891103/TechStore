# TechStore - E-commerce de Óptica

Plataforma moderna de e-commerce especializada en óptica con backend en Node.js + SQLite y app móvil en React Native.

## 🚀 Inicio Rápido

```bash
# Backend
cd TechStore
npm install
npm start

# Frontend (en otra terminal)
cd TechStore/mobile
npm install
npm start
```

- API: `http://localhost:3000`
- Docs Swagger: `http://localhost:3000/api/docs`
- Expo: Escanea el QR generado
